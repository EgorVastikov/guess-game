# guess-game

Детская игра «Угадай предмет/животное»: ответы «да», «нет» и «не знаю».
Обычная партия — 10 вопросов, для сложных слов — 15. Попытка угадать: «Это кошка?».
Когда остаётся не больше трёх вопросов, игра может показать подсказку о категории.

Ссылка на игру: https://guess-game-utl.pages.dev/

## Структура

- `public/index.html` — интерфейс, CSS и браузерный JavaScript без сборки.
- `shared/rules.js` — словарь, признаки, сложность, распознавание вопросов.
- `shared/store.js` — общее хранилище игр: память или Upstash Redis.
- `shared/ai.js`, `shared/prompts.js`, `shared/config.js` — клиент OpenRouter, инструкции и лимиты по задачам.
- `shared/game.js` — создание партии и обработка хода.
- `shared/adapters.js` — адаптеры Node.js и Cloudflare Pages к общей логике.
- `api/` — точки входа Node.js; `functions/api/` — точки входа Pages Functions.
- `dev-local.js` — сервер Node.js для локального запуска, Render и Docker.
- `tests/` — автоматические проверки без обращений к внешним сервисам.

Весь серверный код использует ES Modules. Игровые правила общие для обеих платформ.
Подсказки по кнопке доступны в текущей игре. Для будущих аналитики и рисования подготовлены отдельные инструкции и настройки клиента ИИ.

## Подсказки

Кнопка «Подсказка» предлагает направление следующего вопроса. На партию доступно две подсказки;
они не уменьшают остаток вопросов. Под кнопкой видны счётчик и все полученные подсказки.
После окончания партии кнопка недоступна, а при новой игре список и лимит сбрасываются.
Существующая автоматическая подсказка о категории в конце партии сохранена отдельно от этого лимита.

Для подсказок нужен `OPENROUTER_API_KEY`. Модель задаётся через `MODEL_HINT`, иначе используется `MODEL`.
ИИ получает секретное слово, полную историю и предыдущие подсказки, затем выбирает направление из предложенных сервером.
Сервер исключает уже проверенные признаки, равнозначные им направления и ранее предложенные подсказки.
Модель возвращает JSON с ключом направления; пользователю показывается только готовый текст сервера.
Это не позволяет ответу модели раскрыть слово или вставить произвольный текст в подсказку.

Если ИИ недоступен, исчерпана квота, ответ некорректен или сохранение не удалось,
подсказка не возвращается как успешная и можно продолжить обычную игру. При потере сети после сохранения
следующий успешный запрос получает актуальный список подсказок с сервера.

`POST /api/hint` принимает `{ "gameId": "..." }`. Ответ содержит `hints` (список текстов),
`hintsUsed`, `hintsLeft`, `hintLimit`, а также текущее состояние партии.
Повтор после исчерпания лимита или окончания игры возвращает HTTP 409, ошибка ИИ или Redis — HTTP 503.
Неверный `gameId` — HTTP 400, отсутствующая партия — HTTP 404. Клиент не может изменить лимит в запросе.

## Локальный запуск

Нужен Node.js 20 или новее. Внешних npm-зависимостей и шага сборки нет.

```powershell
npm start
```

Открыть `http://localhost:3000`. Если порт занят и `PORT` не задан, сервер пробует `3001`.
Без ключа OpenRouter работают встроенные признаки и попытки угадать; остальные вопросы получают «не знаю».

Пример настройки в PowerShell:

```powershell
$env:STORE_KIND = "memory"
$env:OPENROUTER_API_KEY = "<ключ OpenRouter>"
$env:MODEL = "nvidia/nemotron-3.5-super-vl:free"
npm start
```

Шаблон настроек — `.env.example`. `npm start` не загружает `.env` автоматически.
На Node.js с поддержкой `--env-file` можно скопировать шаблон в `.env`, заполнить его и запустить:

```powershell
node --env-file=.env dev-local.js
```

`.env`, `.dev.vars` и их локальные варианты исключены из Git. `.env.example` хранится в репозитории.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `PORT` | Порт Node.js-сервера | `3000` |
| `STORE_KIND` | `memory` или `upstash` | Автовыбор: Upstash при наличии обоих реквизитов, иначе память |
| `UPSTASH_REDIS_REST_URL` | REST-адрес Upstash | Не задан |
| `UPSTASH_REDIS_REST_TOKEN` | Секретный токен Upstash | Не задан |
| `OPENROUTER_API_KEY` | Секретный ключ OpenRouter | Не задан; ИИ отключён |
| `OPENROUTER_BASE_URL` | Базовый адрес API | `https://openrouter.ai/api/v1` |
| `MODEL` | Общая модель, в том числе для игровых ответов | `nvidia/nemotron-3.5-super-vl:free` |
| `MODEL_HINT` | Модель для текстовых подсказок | Значение `MODEL` |
| `MODEL_ANALYSIS` | Модель для будущего разбора игры | Значение `MODEL` |
| `MODEL_VISION` | Модель для будущего распознавания рисунков | Значение `MODEL` |

Пустые значения считаются незаданными. Для `STORE_KIND` неизвестное значение является ошибкой конфигурации.
Ключи и токены остаются на сервере. Для игрового ответа в OpenRouter передаются секретное слово, вопрос и до шести последних вопросов с ответами;
для подсказки — вся история, ранее полученные подсказки и доступные направления.
В будущем режиме рисунков инструкция передаёт только изображение, без правильного ответа.

Клиент использует `POST /chat/completions`, `temperature: 0` и `reasoning.enabled: false`.
Модель должна поддерживать соответствующий режим ввода; для рисунков нужен ввод изображений.
Доступность бесплатной модели и квота зависят от OpenRouter и провайдера.

| Задача ИИ | Максимум токенов ответа | Таймаут |
|---|---:|---:|
| Игровой ответ | 32 | 9 секунд |
| Подсказка | 160 | 9 секунд |
| Аналитика (заготовка) | 1000 | 15 секунд |
| Рисунок (заготовка) | 256 | 15 секунд |

Каждая операция Redis ограничена 2,5 секунды. Текущий ход занимает до 14 секунд по серверным лимитам;
браузер ждёт 20 секунд. Для будущих аналитики и рисунков таймаут интерфейса нужно выбирать с учётом их отдельных лимитов.
Сбой или ограничение квоты ИИ возвращает HTTP 503, не расходуя ход. Ответ «не знаю» от самой модели расходует ход.

## Хранение

Партия содержит секрет, остаток вопросов, историю, сложность, результат, время последнего хода,
список подсказок с временем получения и внутреннюю версию состояния.
Повторный вопрос раньше чем через 700 мс получает сообщение ожидания без расходования хода.

- `memory`: данные одного процесса, срок жизни один час после сохранения; перезапуск удаляет все партии.
  Не подходит для нескольких экземпляров приложения и Cloudflare Pages.
- `upstash`: JSON под ключом `game:<gameId>`, срок жизни один час после сохранения.
  Новая партия записывается командой `SET ... EX 3600` через REST. Обновления используют Lua-скрипт через `EVAL`,
  который атомарно проверяет версию и сохраняет новое состояние со сроком жизни.
  Ошибки чтения или записи возвращаются как HTTP 503, без ложного сообщения об успешном сохранении.

Параллельные ходы и запросы подсказок защищены от перезаписи: устаревшее обновление возвращает HTTP 409
с предложением повторить действие. Такая же проверка версий действует в памяти.
Старые партии без списка подсказок и версии поддерживаются до истечения их срока жизни.

Состояние игры в браузере не восстанавливается после перезагрузки страницы.

## Render

Используется `render.yaml`: установка `npm install`, запуск `npm start`, Node.js 20.
В настройках сервиса нужно задать `OPENROUTER_API_KEY`, `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
В конфигурации выбран `STORE_KIND=upstash`. Health check `/` проверяет доступность страницы, а не внешних сервисов.

## Docker

```powershell
docker build -t guess-game .
docker run --rm -p 3000:3000 --env-file .env guess-game
```

Перед запуском создать `.env` из `.env.example` и заполнить настройки. Сервер внутри контейнера слушает `0.0.0.0:3000`;
при изменении `PORT` нужно изменить и проброс порта.

## Cloudflare Pages

Подключить репозиторий к Pages, корень проекта — корень репозитория, выходная папка — `public`, команда сборки не требуется.
Pages собирает обработчики из `functions/` вместе с импортируемыми модулями `shared/`.
Для Pages использовать `STORE_KIND=upstash`, задать адрес Redis, токен и ключ OpenRouter.
Production и Preview настраиваются отдельно; `.env` с компьютера на хостинг не переносится.

Локальная проверка при установленном Wrangler: `wrangler pages dev public`.
Для этого окружения локальные секреты можно задать в `.dev.vars`, используя имена из `.env.example`.
Wrangler не является зависимостью приложения.

## Проверки

```powershell
npm test
```

Проверки используют встроенный `node:test`, реальные обработчики обеих платформ, временный HTTP-сервер и подмену OpenRouter/Redis.
Секреты и сетевые запросы к внешним сервисам для тестов не нужны.
