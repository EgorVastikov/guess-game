# Состояние реализации и подготовка выпуска

Реализованы оба режима игры, наводящие подсказки и разбор завершённой партии.
Реальные испытания ИИ отложены по просьбе пользователя. Внешнее хранилище и целевой хостинг также пока не проверены.
Не следует считать технические проверки с заглушками подтверждением качества модели.

## Техническая часть

- [x] Единая игровая логика для Node.js и Cloudflare Pages.
- [x] Лимит подсказок, статистика, сохранение разбора, изоляция режима рисунков.
- [x] Рисование мышью и сенсорным вводом, инструменты, повторная отправка и подтверждение.
- [x] Обработка отказов ИИ, квот, некорректных ответов и конфликтов сохранения.
- [x] Проверка всех слов словаря: точная догадка засчитывается даже при совпадении с названием признака.
- [x] Работа первого экрана без доступа к localStorage, узкие и горизонтальные экраны.
- [x] Сохранение рисунка и введённого вопроса при сетевом сбое.
- [x] Ограничения входного PNG/JSON и границ папки со статическими файлами.
- [x] Общая команда `npm run verify`, настройки CI и единая версия Node.js 22.
- [x] Подготовлены настройки Render, Docker и инструкции для Pages.

Проверки выполняются без ключей и npm-зависимостей. CI будет выполнен GitHub после отправки коммита;
его успешный результат на удалённых runners заранее не предполагается.

## Проверки после подключения внешних сервисов

### Качество ИИ

- [ ] Прогнать вопросы с известными ответами, переформулировками и неоднозначными формулировками.
- [ ] Проверить, что подсказки полезны, не повторяют выясненное и не раскрывают секрет.
- [ ] Сравнить разбор победы и поражения, партий с повторами и неточными ответами игры.
- [ ] Проверить понятность и доброжелательность текста для ребёнка.
- [ ] Проверить распознавание набора простых и неоднозначных детских рисунков.
- [ ] Измерить время ответа, проверить реальные лимиты выбранной бесплатной модели.

Встроенный разбор вопросов использует эвристическое распознавание признаков. Его точность на свободных
формулировках нужно оценить отдельно: наличие ИИ не означает, что каждый вопрос действительно будет отправлен модели.

### Внешняя инфраструктура

- [ ] Проверить чтение, запись, TTL и Lua-обновление на настоящем Upstash.
- [ ] Собрать и запустить Docker-образ в целевом окружении.
- [ ] Проверить сборку и маршруты настоящего Cloudflare Pages либо запуск Render.
- [ ] На опубликованной версии проверить оба режима с компьютера и телефона.
- [ ] Только после этих проверок переносить подготовленный выпуск в `main` для публикации.

Ни Docker-образ, ни Cloudflare/Render из этой сессии не публиковались.

## Когда будет добавлен ключ

Скопировать `.env.example` в `.env`, заполнить настройки и выполнить `npm start`.
Сервер читает `.env` автоматически; для запуска без ИИ создавать этот файл не требуется.
Для испытаний доступны `MODEL`, `MODEL_HINT`, `MODEL_ANALYSIS` и `MODEL_VISION`.
У последней модели должен быть ввод изображений. Для нескольких экземпляров приложения нужно общее хранилище Upstash.
